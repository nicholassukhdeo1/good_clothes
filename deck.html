final = 0.4 × materials + 0.4 × ethics + 0.2 × ownership
How it works

Three layers, one badge.

01 — Read the page

Instant materials score

The extension parses fiber composition directly from the product page. Deterministic, no API call, loads in milliseconds.

02 — Research the brand

Live ethics check

A Browserbase web agent gathers evidence on labor practices and ownership. Claude synthesizes it into a sourced score.

03 — Find better that fits

Vision-guided alternatives

Claude reads the product photo, describes the look, and returns conscious brands — each with a direct search link for that exact color and silhouette.

Built with

Every sponsor is load-bearing.

Claude (Anthropic)
Brand ethics synthesis (text) + product look extraction (vision). Two distinct use cases in one model.
Browserbase
Headless Playwright browser for live brand research. Fetches real pages that block scrapers.
Supabase
Persists style preferences per anonymous install. PostgREST API, RLS on, no login required.
FastAPI · Render
Always-on Python backend. Deployed live — this is not a mock. Auto-redeploys on every push.
